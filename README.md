# LVS Control (Android)
Приложение-пульт для ESP32-эмулятора (firmware_v3.ino).

## Сборка APK без Android Studio
1. Создайте репозиторий на GitHub и загрузите содержимое этой папки (включая .github).
2. Вкладка Actions → build-apk → Run workflow (или просто push).
3. Через ~3–5 минут: артефакт lvs-control-apk → app-debug.apk. Установите на телефон (разрешить установку из неизвестных источников).

## Сборка в Android Studio
Open → выбрать папку → Build → Build APK(s).
